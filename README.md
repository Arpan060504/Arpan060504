## `$ whoami`

I'm an Electrical Engineering student at **NIT Durgapur** building a career in **digital VLSI and front-end chip design**.

- 🔧 Working with **Verilog, RTL design, processor architecture, and hardware accelerators**.
- 🧪 Learning **SystemVerilog-based verification** and strengthening my testbench and debugging skills.
